ScribeSense

A Linux tool that makes text easier to read for people with dyslexia by changing letter, word and line spacing across the whole desktop: browsers, documents and apps. It does this by generating spaced-out fonts and pointing every app it can reach at them, with a pop-up reader for anything it can't reach.

  • Platform Hyprland on Linux
  • Language English (Latin letters)
  • Built in Python · extension in JavaScript
  • MVP deadline 20 October
  • Team 4 owners, O1–O4
  • Status design drafted · mentor review pending

The core idea

Spacing lives inside the font

Linux lets you change the font and the text size, but not the spacing. So ScribeSense builds the spacing into a new font file: wider letters give letter spacing, a wider space character gives word spacing, and taller line metrics give line spacing. Then it tells the system and each app to use that font. Each preset gets two fonts: a reading font with full line height, and a UI font with smaller line height, because tall line spacing cut off text in Qt menus during testing.

Reading is easier when letters have room to breathe. Some readers need more space between words, others need more space between lines, and the right amount differs from person to person. ScribeSense lets each reader choose, then applies that choice everywhere they read.

Default · letter 0.12 em · word +0.16 em · line 1.5× An approximate preview drawn with CSS in your browser. ScribeSense itself puts these values into the font. Preset values are drafts.

Safety and privacy rules

ScribeSense edits other programs' settings, and its users already find reading hard. A mistake must never leave someone with a screen they can't read.

  • Nothing is changed before its old value is recorded.
  • After applying: 30 seconds to confirm, or everything is undone.
  • A crash or reboot before confirming is undone at the next login.
  • Recovery keybind Ctrl+Alt+Shift+Super+Backspace works without the app window.
  • If the user changed a setting after us, undo skips it and says so.
  • Apps are never closed or restarted by ScribeSense. The user is asked.
  • Text from the reader stays in memory for the session only. Never saved, never logged.
  • No network: no servers, no downloaded fonts.
  • Monospace and icon fonts are never changed.
  • Uninstall undoes everything and keeps the user's presets unless they ask to delete them.
